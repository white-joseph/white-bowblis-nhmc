\begin{tablenotes}[flushleft]
\footnotesize
\item \textit{Notes:} Each cell reports the coefficient on \textit{post}, with standard errors in parentheses. All specifications include facility and calendar-quarter fixed effects and control for the number of certified beds. Standard errors are two-way clustered by facility and calendar quarter. The ownership-change quarter ($\tau = 0$) is excluded.
\item Column (1) is the baseline specification. Column (2) adds RN, LPN, and CNA hours per resident day as controls; because staffing is itself affected by ownership change, column (2) is descriptive rather than an estimate of the total effect. Columns (3) and (4) re-estimate column (1) separately for facilities that were chain-affiliated and independent at baseline. A facility is chain-affiliated if its cost report lists a home office. Baseline affiliation is measured in January 2017, or at the facility's first observation if it is not observed then.
\item Each measure is a percentage of residents, so coefficients are in percentage points. Long-stay measures (Panels A and B) and short-stay measures (Panel C) come from different resident populations. Lower values indicate better quality for every measure except improved function, for which higher values are better.
\item Pressure injuries are estimated on 2018--2023 and improved function on 2017--2022, the years in which each is reported.
\item Statistical significance: $^{***}p<0.01$, $^{**}p<0.05$, $^{*}p<0.10$.
